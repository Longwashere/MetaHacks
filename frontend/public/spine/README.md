# Example Spine rigs (development only)

These are Esoteric Software's official Spine 4.2 example exports (spineboy, raptor, goblins,
coin, owl, powerup, alien, celestial-circus, chibi-stickers, cloud-pot, dragon, hero,
mix-and-match, sack, snowglobe, speedy, stretchyman, tank, vine, windmill), copied from
https://github.com/EsotericSoftware/spine-runtimes/tree/4.2/examples so the viewer has real
data before the backend exists.

They're covered by the Spine Runtimes License / Spine Editor License and are meant for
evaluation and testing. Don't ship them as library content in production — delete this
folder once real assets are served by the backend.
